# M3.1.3 fractional interval boundaries

## Scope and acceptance

Authorised by the maintainer on 11 November 2026. Editor: Codex; verification: automated regression
tests and author-run browser/Python fixture checks. No independent reviewer is assigned.

The canonical conversion evaluates `(bottom - top) * unit_factor`, divides analysis rows by that span
to obtain pixels per centimetre, then multiplies by the requested interval in centimetres. This is the
existing application order and the documented `bin_cm * ppcm` definition. Python now uses the same
order. Neither the half-up edge rule nor the 1e-9 absolute comparison tolerance changes. No epsilon,
decimal rounding, dependency, new algorithm or performance optimisation is introduced.

Acceptance was set before validation: exact shared row boundaries at half rows and adjacent binary64
values; both M0.1 fixtures agree at 2 and 1.37 cm within 1e-9 for depths/percentages, with exact indices
and missing values; historical, default/integer and explicit pixel-interval outputs remain equivalent.

```sh

python tools/sync_version.py --check
```

The unchanged profiling harness retains its diagnostic failure reporting. Acceptance here explicitly
requires `complete` and `scientific_parity_passed` to be true, not merely successful process exit.
Each case must also report unchanged inputs, matching M0.1 input/result fingerprints and saved reload.
Compare `analysis_input_sha256`, `interval_sha256` and `python_interval_sha256` with the original
[V0.120 report](M3.1.2-v0.120.json) to distinguish preserved results from corrected Python output.

## Regression coverage

Both test suites consume the same fixed [boundary fixtures](../../tests/fixtures/fractional-boundaries.json).
Twenty cases cover the two measured 7,450-row sections, metre/centimetre/millimetre depth metadata,
1.37 cm and its immediately adjacent representable values, and 1/2 cm intervals. They assert complete
row-edge arrays, not approximate depths alone. Explicit 68.5-row edges also use the independent
integer rule `(137*j + 1) // 2`; adjacent floats distinguish first edges 68 and 69. The Python tests
verify final partial-bin removal, exact mapped depths, exclusions/missing values and class results,
and exact equivalence with the former conversion for these default/integer cases.

A hand-computed mask places its only bioturbated pixel in row 68 of the measured section 2 geometry.
The first interval includes 69 rows, ends at 1.5138 m and has `100/69` percent bioturbation, BI 1 and
ii 2. The next interval has zero bioturbation. This explicitly checks the intended scientific result,
in addition to edge equivalence. Existing tests retain the legacy v2.1 CSV regression and API contracts.
