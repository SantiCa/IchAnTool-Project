# Revistas candidatas

No se incluyen factores de impacto ni APC: cambian cada año. Verificar en la web de cada
revista antes de enviar.

## Software y métodos computacionales
| Revista | Editorial | Acceso | Encaje |
|---------|-----------|--------|--------|
| Journal of Open Source Software (JOSS) | Open Journals | Abierto, sin coste | Artículo corto + revisión del código en GitHub. Ideal para IchAnTool 3. |
| Computers & Geosciences | Elsevier | Híbrido | Donde se publicó la v2.1 (2020). Bueno para un método nuevo (segmentación automática). |
| Applied Computing and Geosciences | Elsevier | Abierto | Revista hermana de C&G, orientada a aplicaciones y software. |
| Artificial Intelligence in Geosciences | KeAi | Abierto | Encaje directo si el aporte principal es el modelo de deep learning. |
| Geoscientific Instrumentation, Methods and Data Systems | Copernicus | Abierto | Métodos y sistemas de datos; alternativa a C&G. |

## Criterios para elegir
1. ¿El aporte es el software, los datos, el método o la interpretación geológica? Eso decide la familia de revistas.
2. Acceso abierto: aumenta adopción de la herramienta; JOSS y Copernicus no cobran o cobran poco.
3. Plazo: JOSS y las revistas de datos suelen ser más rápidas que las de paleoambiente.
